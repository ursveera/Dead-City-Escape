Dead City Escape

Two-Person Work Responsibility Document — Written from the owner’s side for direct project communication with Sitrarasan.
Owner: Me 3D Artist: Sitrarasan Unity 6 2-Player Co-op Zombie Survival Shooter

1. Project Introduction

I am developing a game called Dead City Escape.

This game is a 2-player co-op zombie survival shooter built in Unity.

For this project, I will handle the game development, game design, level design, multiplayer, zombie AI, UI, sound integration, testing, and publishing.

Sitrarasan, you will handle all 3D model and 3D art-related work for this game.

Main goal: We will first create a small 10-minute playable demo. After that works well, we will expand the game area by area.

2. Our Team Structure

Person Role Work Responsibility
Me Owner / Game Developer / Game Designer / Level Designer I will manage the full project, build the game in Unity, create the gameplay systems, create the level graybox, handle multiplayer, zombie AI, UI, sound, testing, and publishing.
Sitrarasan 3D Artist You will design and create all 3D models, environment assets, characters, zombies, weapons, props, textures, and Unity-ready art assets.

3. My Work in This Project

I will take care of all game-side work except 3D modeling.

Area My Responsibility
Game Direction I will decide the game vision, story direction, gameplay style, horror mood, quality target, and production priorities.
Production Management I will create the task list, assign 3D asset work, review your models, approve or ask for changes, and manage the timeline.
Game Design I will design the weapons, zombies, objectives, co-op rules, player health, revive system, difficulty, and game flow.
Level Design I will create the graybox level layout, player path, combat flow, zombie spawn points, objective locations, and co-op movement spaces.
Unity Development I will build player movement, camera, shooting, reload, health, inventory, interaction, objectives, pickups, and gameplay logic.
Multiplayer I will build the 2-player co-op system, lobby, player spawning, network sync, zombie sync, damage sync, and revive sync.
Zombie AI I will create zombie detection, chase, attack, death, wave spawning, and horde events.
UI / UX I will create the HUD, health UI, ammo UI, objective UI, revive UI, lobby UI, and interaction prompts.
Sound and VFX Integration I will integrate gun sounds, zombie sounds, rain, ambience, blood effects, muzzle flash, fire, sparks, and other effects inside Unity.
Testing and Publishing I will test bugs, fix gameplay problems, optimize performance, create builds, and prepare the game for release.

5. First Demo Target

Our first target is not the full game. Our first target is a 10-minute playable demo.

The demo should include:

  • Start Alley area
  • Main Street area
  • 2-player co-op movement
  • Pistol shooting
  • Basic zombie AI
  • One survivor model
  • One zombie model
  • Basic environment assets
  • One small objective: reach the exit gate

9. 3D Asset Quality Rules

  • All models should match the horror survival style of Dead City Escape.
  • The world should look dirty, wet, damaged, abandoned, and recently collapsed.
  • Do not make cartoon-style models.
  • Do not make clean and empty-looking assets.
  • Use realistic proportions.
  • Make assets optimized for real-time gameplay.
  • Use correct scale: 1 Unity unit = 1 meter.
  • Keep pivots correct.
  • Use proper naming.
  • Give FBX, textures, and preview images for every final asset.
