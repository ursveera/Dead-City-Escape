ReviveDowned state, revive progress, recovery

Performance Targets

  • 60 FPS target on mid-range PC.
  • Use LODs for zombies, vehicles, hero props.
  • Use occlusion culling in city, hospital, and garage.
  • Limit active zombies with spawn manager and pooling.
  • Use object pooling for bullets, blood VFX, impact VFX, zombie spawns.
