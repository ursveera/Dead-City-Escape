05. Level Design Document

Dead City Escape — Production Document

Level Flow

Start Alley → Main Street → Gun Shop → Hospital → Underground Parking → Generator Room → Final Gate Arena → Escape

Design Rules

  • Always support two-player movement.
  • Use clear landmarks for navigation.
  • Alternate tension, combat, exploration, and reward.
  • Every combat arena needs entry points, cover, flanking routes, and fallback space.
